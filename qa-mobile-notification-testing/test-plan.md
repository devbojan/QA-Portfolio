# Test Plan – Occasion.ly Mobile App

## 1. Objective
To validate the functionality, reliability, and accuracy of the notification system and scheduling logic in the Occasion.ly mobile application.

## 2. Scope

### In Scope
- Creating reminders
- Scheduling notifications (date/time)
- Recurring reminders
- Push notifications delivery
- Editing and deleting reminders

### Out of Scope
- Payment features (if any)
- Third-party integrations

## 3. Test Types
- Functional Testing
- Exploratory Testing
- Regression Testing
- Usability Testing

## 4. Test Environment
- Android device / emulator
- Stable internet connection
- App version: latest

## 5. Entry Criteria
- App installed successfully
- User logged in (if required)

## 6. Exit Criteria
- All critical test cases executed
- No high severity bugs open

## 7. Risks
- Notification delays due to OS restrictions
- Timezone inconsistencies
- Background app limitations
