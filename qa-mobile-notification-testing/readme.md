# 🧪 Occasion.ly – Mobile Notification & Scheduling QA Testing

## 📌 Overview

This project documents the **manual testing process** of a mobile reminder application *Occasion.ly*, with a strong focus on **notification systems** and **scheduling logic**.

The goal was to validate how the application behaves in real-world scenarios, including background execution, time-based triggers, and edge cases related to time and device behavior.

---

## 🎯 Testing Objectives

* Verify accuracy of reminder scheduling
* Validate push notification delivery
* Ensure correct behavior in background mode
* Identify edge cases related to time and system constraints
* Detect usability and functional issues
