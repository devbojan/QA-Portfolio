#QA Manual Testing Portfolio - Mobile Bank QA Project 

## 🚀 Author
Bojan Brankovic 

## Project Overview
This project focuses on manual testing of a mobile banking application, covering core financial functionalities, user workflows, and security-related scenarios.

## Scope
- User registration & login
- Account dashboard
- Money transfer (internal/external)
- Transaction history
- Notifications & alerts
- Security features (PIN, session handling)

## Tools Used
- Manual Testing
- Postman (API testing)
- Excel / Google Sheets
- Android Emulator / Real Device

## Testing Types
- Functional Testing
- Regression Testing
- UI/UX Testing
- Exploratory Testing
- API Testing (basic)

## Deliverables
- Test Plan
- Test Strategy
- Test Cases (20+)
- Bug Reports
- Test Execution Report
- Traceability Matrix

## Key Bugs Found
- Failed transaction without proper error message
- Session timeout not triggered after inactivity
- Incorrect balance update after transfer
- UI misalignment on transaction history screen
- API returns 200 OK on failed transfer

## Conclusion
The testing process identified several critical and high-priority issues, particularly in transaction handling and session management. Addressing these bugs is essential to ensure a secure, reliable, and user-friendly mobile banking experience.
