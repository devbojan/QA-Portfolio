# 🧪 QA Manual Testing Portfolio - E-commerce web application

## 🚀 Author
Bojan Brankovic

## 📌 Project Overview
This project focuses on manual testing of an e-commerce web application.

## Scope
- User registration & login
- Product search
- Cart functionality
- Checkout process

## Tools Used
- Manual Testing
- Postman (API testing)
- Excel

## Testing Types
- Functional Testing
- Regression Testing
- UI Testing

## Deliverables
- Test Plan
- Test Cases (20+)
- Bug Reports
- Test Execution Report

## Key Bugs Found
- Checkout failure during payment
- Login error with valid credentials
- UI inconsistency in cart page

## Conclusion
Critical issues found in checkout process affecting user experience.
