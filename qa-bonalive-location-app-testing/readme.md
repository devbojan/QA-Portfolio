# 🧪 BonaLive – Mobile Map Application QA Testing

## 📌 Overview
This project represents the testing of the BonaLive mobile application, focusing on map functionality, real-time location tracking, and user experience.

The testing was performed as part of real-world QA activities on a live application.

---

## 🎯 Testing Objectives
- Validate map loading and interaction
- Ensure accurate location tracking
- Test app stability under real-world conditions
- Identify performance and usability issues
