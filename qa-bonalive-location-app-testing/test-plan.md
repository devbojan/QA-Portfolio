# Test Plan – BonaLive Personal Map App

## 1. Objective
To validate the functionality, performance, and reliability of the BonaLive mobile application, focusing on map features, user interaction, and real-time data handling.

## 2. Scope

### In Scope
- User navigation and map loading
- Location tracking
- Map interactions (zoom, pan)
- Real-time updates
- UI responsiveness

### Out of Scope
- Third-party integrations (if not accessible)
- Payment features

## 3. Test Types
- Functional Testing
- Exploratory Testing
- Usability Testing
- Performance Testing (basic)

## 4. Test Environment
- Android device (Samsung Galaxy A8)
- Stable internet connection
- App version: tested build

## 5. Entry Criteria
- App installed successfully
- Location permissions enabled

## 6. Exit Criteria
- All critical scenarios tested
- No high severity issues open

## 7. Risks
- GPS inaccuracies
- Slow map rendering
- App crashes on data load
