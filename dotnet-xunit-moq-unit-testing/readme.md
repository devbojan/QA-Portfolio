# .NET xUnit + Moq Unit Testing Demo

## 📌 Overview
This project demonstrates unit testing in .NET using:
- xUnit
- Moq (mocking framework)
- FluentAssertions (clean assertions)

The goal is to showcase testing of the service layer with isolated dependencies.

---

## 🧱 Project Structure

QaXunitDemo/
├── Models/
├── Interfaces/
├── Services/
├── Tests/

---

## 🧪 What is Covered

- Unit testing business logic (UserService)
- Mocking dependencies using Moq
- Positive and negative test scenarios
- Exception testing
- Method verification (Verify)

---

## 🔧 Tech Stack

- .NET 8
- xUnit
- Moq
- FluentAssertions
