# Test Plan – Eye-Net Mobile

## 1. Objective
To validate functionality, reliability, and performance of the Eye-Net mobile application, with focus on real-time collision alerts, notifications, and location-based behavior.

## 2. Scope

### In Scope
- Collision warning system
- Real-time notifications
- GPS accuracy and proximity detection
- App behavior (foreground/background)
- Network handling (online/offline)

### Out of Scope
- Backend algorithms (if not accessible)
- Third-party integrations

## 3. Test Types
- Functional Testing
- Exploratory Testing
- Real-time Scenario Testing
- Performance Testing (basic)
- Usability Testing

## 4. Test Environment
- Android device (real device preferred)
- GPS enabled
- Mobile data / WiFi
- App version: tested build

## 5. Entry Criteria
- App installed successfully
- Permissions enabled (Location, Notifications)

## 6. Exit Criteria
- Critical safety features tested
- No high-severity defects open

## 7. Risks
- GPS inaccuracies
- Delayed or missed alerts
- App instability in background mode
