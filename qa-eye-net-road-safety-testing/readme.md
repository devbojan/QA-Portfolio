# 🧪 Eye-Net Mobile – Real-Time Safety App QA Testing

## 📌 Overview
This project documents the QA testing of a real-time mobile application focused on driver safety and collision alert systems.  

The testing effort targets critical features such as real-time notifications, GPS accuracy, and system reliability in dynamic, real-world scenarios.

---

## 🎯 Testing Objectives
- Validate real-time collision alert functionality  
- Ensure accurate GPS tracking and proximity detection  
- Verify notification delivery across different app states  
- Assess application stability in real-world conditions  

---

## 🧪 Testing Types Applied
- Functional Testing  
- Exploratory Testing  
- Real-Time Scenario Testing  
- Usability Testing  
- Basic Performance Testing  

---

## 🧩 Key Test Areas

### 🚨 Real-Time Alerts
- Collision warning triggers  
- Alert timing and accuracy  
- False positives / missed alerts  

### 📍 Location & GPS
- Real-time tracking accuracy  
- Location drift and precision  
- Movement-based scenarios  

### 🔔 Notifications
- Foreground vs background behavior  
- Delivery timing and reliability  
- Notification consistency  

### 📱 App Behavior
- Background execution  
- App resume functionality  
- Permission handling
