# 🧪 8 Ball Saloon Billiard – Mobile Game QA Testing

## 📌 Overview
This project documents the QA testing of a mobile billiard game developed by Tuphan Games, focusing on UI consistency, localization, and gameplay stability.

---

## 🎯 Testing Objectives
- Validate core gameplay functionality
- Ensure UI consistency across devices
- Verify localization accuracy
- Identify performance and stability issues

---

## 🧪 Testing Types Applied
- Functional Testing  
- UI/UX Testing  
- Localization Testing  
- Compatibility Testing  
- Exploratory Testing  

---

## 🧩 Key Test Areas

### 🎮 Gameplay
- Game mechanics  
- Controls and physics  

### 🖥️ UI/UX
- Layout consistency  
- Scaling across devices  

### 🌍 Localization
- Language switching  
- Translation accuracy

## 🐞 Key Issues Identified

- Missing translations in dropdown menus  
- UI scaling issues across devices  
- Text overflow in certain languages  
- Performance lag during extended gameplay  

---

## 🧠 Key QA Contributions

- Identified localization defects impacting user experience  
- Validated UI responsiveness across multiple devices  
- Performed exploratory testing for real gameplay scenarios  
- Contributed to improving game stability and usability
