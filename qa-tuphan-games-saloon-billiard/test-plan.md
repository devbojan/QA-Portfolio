# Test Plan – 8 Ball Saloon Billiard

## 1. Objective
To validate functionality, usability, and performance of the 8 Ball Saloon Billiard mobile game, focusing on UI consistency, localization, and cross-device compatibility.

## 2. Scope

### In Scope
- Game launch and navigation
- Gameplay mechanics
- UI elements and responsiveness
- Localization (multi-language support)
- Device compatibility (screen sizes, resolutions)

### Out of Scope
- Multiplayer backend (if not accessible)
- Payment systems

## 3. Test Types
- Functional Testing
- UI/UX Testing
- Exploratory Testing
- Compatibility Testing
- Localization Testing

## 4. Test Environment
- Android device (Samsung Galaxy A8)
- Different screen resolutions (simulated)
- Various language settings

## 5. Entry Criteria
- Game installed successfully
- Device meets minimum requirements

## 6. Exit Criteria
- Core gameplay tested
- No critical UI or crash issues

## 7. Risks
- UI scaling issues across devices
- Missing translations
- Performance lag during gameplay
