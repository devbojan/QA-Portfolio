# 🧪 Café-Restaurant Management System – QA Testing

## 📌 Overview
This project represents the testing process of a desktop-based restaurant management system developed in .NET (C#) with SQL Server.

The focus is on validating core functionalities such as order management, billing logic, and role-based access control.

---

## 🎯 Testing Objectives
- Verify correctness of billing calculations
- Validate order creation and management
- Ensure proper role-based access control
- Confirm data integrity in the database

---

## 🧪 Testing Types Applied
- Functional Testing  
- Integration Testing  
- Data Validation Testing  
- Exploratory Testing  

---

## 🧩 Key Test Areas

### 🔐 Authentication & Roles
- Login validation  
- Role-based access control  

### 🍽️ Order Management
- Create / update / delete orders  
- Order workflow validation  

### 💳 Billing System
- Total calculation accuracy  
- Pricing validation  

### 🗄️ Database Integrity
- CRUD operations  
- Data consistency
