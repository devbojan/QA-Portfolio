# 🧪 EQtive Fitness App – QA Testing Project

## 📌 Overview

This project documents the **manual testing process** of a mobile fitness application, with a focus on **workout tracking, data accuracy, performance, and real-world user behavior**.

The goal was to validate core functionality and identify potential issues affecting reliability, usability, and user experience.

---

## 🎯 Testing Objectives

* Validate workout session tracking (start/stop)
* Ensure accuracy of recorded data (time, calories, activity)
* Verify app behavior in background mode
* Identify performance issues and UI responsiveness
* Detect functional and usability defects

---

## 🔍 Scope

### ✅ In Scope

* User login
* Workout session management
* Activity tracking (time, calories, reps)
* Session history
* App behavior in background

### ❌ Out of Scope

* Third-party integrations (wearables, if not available)

## 🐞 Key Issues Identified

* Workout sessions not saved under certain conditions
* Incorrect calorie calculations
* App crash when running in background
* Timer freezing during active sessions
* Session history not updating properly
