# Test Plan – EQtive Fitness App

## 1. Objective
To validate the functionality, performance, and usability of the EQtive Fitness mobile application, with focus on workout tracking, user interaction, and data consistency.

## 2. Scope

### In Scope
- User registration & login
- Workout tracking (start/stop sessions)
- Activity data recording (time, reps, calories)
- UI/UX responsiveness
- Session history

### Out of Scope
- Third-party integrations (wearables, if not available)
- Payment features

## 3. Test Types
- Functional Testing
- Exploratory Testing
- Regression Testing
- Usability Testing
- Basic Performance Testing

## 4. Test Environment
- Android device / emulator
- Stable internet connection
- Latest app version

## 5. Entry Criteria
- App installed successfully
- User account created

## 6. Exit Criteria
- All critical flows tested
- No high severity defects open

## 7. Risks
- Inaccurate fitness data tracking
- App crash during workout session
- Performance lag on low-end devices
